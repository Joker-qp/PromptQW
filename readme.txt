====================================================
🤖 Interactive Prompt Architect - Hızlı Başlangıç
====================================================

Gereksinim:
- Bilgisayarınızda Python 3 yüklü olmalıdır.

Nasıl Çalıştırılır?
- Windows kullanıyorsanız: "BAŞLAT.bat" dosyasına çift tıklayın.
- Linux / Mac kullanıyorsanız: "BAŞLAT.sh" dosyasını çalıştırın.

Uygulama Açıldıktan Sonra:
1. Uygulama otomatik olarak tarayıcınızda açılacaktır (http://localhost:8501).
2. Sol yan panelden Gemini veya OpenRouter API anahtarınızı girip "Ayarları Kaydet" butonuna basın.
3. Artık fikrinizi girip yüksek kaliteli promptlar üretmeye başlayabilirsiniz!
